À propos de School Manager

Cette application pédagogique utilise Django, SQLite et son ORM pour gérer les étudiants et les enseignants de l'école.

Les données sont enregistrées dans la base plutôt que dans les vues. Le personnel autorisé peut les administrer depuis l'interface Django.
